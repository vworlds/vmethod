Keep the watcher quiet on an up-to-date PR: the `nothing to resolve for #n`
conflict-resolution result — the fetched base is already merged in (including
the end of a clean `refresh-checks` update) or update-branch answers 422 with no
new base commits — emits no event, so a base move without conflict no longer
wakes the orchestrator as a false alarm. Record bookkeeping and the
pending-progress cleanup tied to terminal results stay unchanged.
