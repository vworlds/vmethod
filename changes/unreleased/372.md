kind: feature

`vmethod watch --stop` ends this checkout's running watcher: it verifies the
watcher lock's holder record (a live process whose command line is the
`vmethod watch` CLI for that state), signals SIGTERM and waits up to 30 seconds
for the lock to clear, and never sends SIGKILL. `no watcher running` when idle;
a dead or reused holder reports `stale watcher lock (pid <n> not running);
remove with --stop --force`, which removes only that verified-stale lock, while
legacy and foreign holders are refused for inspection. The watcher CLI releases
its lock on SIGTERM, so `pkill -f` pattern kills on watch commands are gone.
