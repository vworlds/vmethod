This release candidate gives one release candidate of warning: the next release candidate after this one will remove the following legacy compatibility paths. They remain supported in this release candidate.

- Legacy bash watcher state import (`legacyState`), including the `legacy-completed.json` and `legacy-turns.json` stamp migration.
- Legacy worker record import (`legacyWorkers`), including `.worktrees_` keys and `claude-workers` records.
- Legacy task headers (`legacyIssueHeaders`): `Closes #n` and `Agent task for #n`.
- The PR 47 non-add-only learnings compatibility.
- The `optionUpdate` restore-journal reader.
- Removed-verb entries in `test/docs-references.test.ts` (`start-task`, `claude-worker` and `start-worker`); these dead table entries are removed now without changing any live verb.

The `kind: claude` worker-record tolerance and `legacyScopeCutoff` remain until the owner confirms every board is past v6.
