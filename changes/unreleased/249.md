open-task's `autopilot` copy no longer loses its delegation to the watcher: the inheritance journals an operation before the label write, and watcher polls leave a task PR's copied label unjudged for the two-minute in-flight window (#199), so a poll between the copied label and its proof write never removes the label. The watcher's own unauthorized-label cleanup is no longer treated as an owner revocation: the affected poll recomputes the task groups after the removal, leaving the issue's delegation active instead of reporting it stopped, and inheritance certification refuses any copy whose label was already removed, so a proof landing after a cleanup cannot retro-activate it. A new orchestrator-only `autopilot inherit <pr>` verb re-runs the authenticated copy from the task's linked live issue grant to repair such a task PR.
