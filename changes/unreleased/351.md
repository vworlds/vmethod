`gh-read` filters GraphQL results field by field and never treats the query's data root as an author-bearing item, so an unaliased top-level `user(login:)` returns a pinned login's data and a non-pinned login is dropped and counted. Account identity is injected regardless of the caller's selection and stripped from the output. REST `user` values act as identities only with REST actor fields (`id` or `type`), and a dropped top-level GraphQL field or single object is counted instead of hiding behind "0 items dropped".
