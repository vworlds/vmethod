kind: feature

`init --launcher [dir]` installs a marked executable `vmethod` launcher (default
`~/.local/bin`) without overwriting other files. It resolves the current checkout
or `VMETHOD_ROOT` and runs only that checkout's installation, including vmethod's
own build output. `check` reports the launcher on PATH and validates environment
overrides. Guides, permission templates and worker onboarding use the short command.
