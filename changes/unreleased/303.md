kind: feature

Workers now end a protocol turn with the report itself instead of a chat
summary nobody reads: the worker guide gains an "Ending a turn" rule — after
posting a protocol comment (READY, QUESTION, DESIGN, BLOCKED or HANDOFF), end
the turn with exactly one line, `<HEADING> posted: <comment url>`, and nothing
else — the worker first prompt carries the same inline rule, and the review
answer/changes and GO wake notifications end with `End your turn with one line
naming what you posted.` The wake documentation in `docs/gateway.md` and the
first-prompt/wake tests assert the new text.
