kind: feature

`open-task --from <branch>` starts a task from work that already exists on another
branch, such as an owner's branch: the source merges into the task branch with a
merge commit, so its commits and authors survive the delivery, and the PR body
records `Started from <branch>`. Conflicting sources are refused with the file
names before anything is pushed. Task opening, start-task and worker start verify
package.json/package-lock.json sync with `npm ci --dry-run`, stopping an
out-of-sync lockfile with a clear one-line error plus npm's first `Invalid:` line
instead of dying in the install.
