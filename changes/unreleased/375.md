kind: feature

Catch a stale scope approval at the edit instead of the merge: `issue edit` on an issue with an approved scope, an open task PR or both reports that the approval is now stale and names the `scope-review <n> <summary-file>` recovery step. `issue edit --scope-review <summary-file>` pairs the body write and the body-bound scope review in one journaled flow, so the review comment's `body sha256:` binds the edited body; under autopilot it approves immediately, otherwise the owner re-approves from Spec review.
