kind: feature

A new `board set <issue|pr> Assignees owner|orchestrator|--clear` verb gives the
orchestrator journaled assignee housekeeping without a turn verb: it sets or clears
the single management assignee on a configured-repository issue or PR card and
validates the request against the card's Status and Progress with the same turn
rules the watcher enforces, refusing a mismatch before any write with the expected
assignee named. Worker assignees are never added or removed, and the assignment
writes are recorded in the gateway write journal, so housekeeping such as clearing
a stale owner assignee from an epic waiting in Executing no longer needs a raw
GitHub write that the session's own watcher misreports as another session's move.
