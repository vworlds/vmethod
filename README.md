# vmethod

VWorlds' shared development methodology, distributed as `@vworlds/vmethod` (Node ≥24, MIT).

Run `npm ci` and `npm run build` to develop locally. See [package commands and adoption](docs/package.md) and the [architecture](docs/architecture.md).

Read the [methodology guides](docs/README.md) for the shared process and the
[consumer templates](templates/README.md) to adopt it.
